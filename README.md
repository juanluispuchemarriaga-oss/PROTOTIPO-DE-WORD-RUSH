# WORD RUSH · Prototipo jugable v0.1
Juego de palabras por turnos contra bots (Fácil / Medio / Difícil). 1 vs 1, 2 vs 2 y 4 jugadores.
Web estática (HTML + CSS + JavaScript), sin dependencias. Pruebas: `node --test tests/engine.test.js`.
Para ampliar el diccionario de demostración crea `palabras_extra.txt` (una palabra por línea).
Limitaciones: diccionario pequeño de demostración, sin servidor, sin cuentas ni economía (XP y monedas solo en tu navegador).
